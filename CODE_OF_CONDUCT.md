# Code of Conduct

This project follows the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Instances of abusive, harassing, or otherwise unacceptable behaviour may be
reported to the maintainers by opening a
[private security advisory](https://github.com/albahq/alba/security/advisories/new)
on this repository. All complaints are reviewed and investigated promptly and
fairly, and the reporter's privacy is respected.
