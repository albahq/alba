# Alba TUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The interactive terminal interface of the [TUI spec](../specs/2026-07-30-alba-tui-design.md): default on a TTY, beam tree + logs + live statuses, fully interactive (rerun, cancel, watch toggle, search, copy, graph view), backed by a commandable `Session` in the engine.

**Architecture:** The engine's watch loop is generalized into a `session` that accepts `SessionCommand`s on an mpsc channel and emits the existing `RunEvent` stream, extended with `RunStarted` and `ProjectBroken`. A new `alba-tui` crate (ratatui + crossterm) consumes events and produces commands; `alba-cli` wires the two together and decides activation. Dependency chain stays strictly downward: `cli → tui → engine → core → syntax`.

**Tech Stack:** Rust (edition 2024, cargo workspace), tokio, ratatui 0.29, crossterm 0.28 (feature `event-stream`), futures 0.3, arboard 3, portable-pty 0.9 (dev), insta (snapshots), assert_cmd.

## Global Constraints

- Spec: `.claude/superpowers/specs/2026-07-30-alba-tui-design.md`. Every behavior below comes from it.
- Dependency direction only ever downward: `alba-cli → alba-tui → alba-engine → alba-core → alba-syntax`.
- Headless **text** output must stay byte-for-byte unchanged (stdout and stderr). The **JSON** stream gains exactly two new event kinds (`run_started`, `project_broken`) — a documented contract addition, nothing else changes.
- Existing watch tests must keep passing on top of the new `session` (spec success criterion).
- Log ring buffer: 10 000 lines per beam, truncation announced, buffer reset when the beam reruns.
- Exit codes: `q` → last run's code **iff it ran to completion**, 130 otherwise; Ctrl-C when idle → 130; Alba startup error → 2. Constants live in `crates/alba-cli/src/exit.rs`.
- TUI floor: below 40 columns × 10 rows, render the "terminal too small" screen instead of the layout.
- Commit messages: gitmoji + Conventional Commits (`✨ feat(tui): ...`). No Claude attribution anywhere.
- All file content in English. TDD: red, green, refactor for every task.
- Run `cargo fmt` and `cargo clippy --workspace --all-targets -- -D warnings` before every commit (CI enforces both).
- When a task adds a dependency, add it to `[workspace.dependencies]` in the root `Cargo.toml` and reference it with `workspace = true` from the crate, like every existing dependency.

```rust
/// A run is beginning. First event of every run, before any
/// `BeamStarted`/`BeamCached`, carrying the snapshot of what this run
```

### Task 2: `ProjectBroken` event — session errors through the stream

Today `watch()` reports mid-session errors through `on_error: &mut (dyn FnMut(&SessionError) + Send)` and the CLI prints to stderr. The TUI needs the diagnostic *in the stream*. Rendering stays in the CLI (the callback's whole reason to exist): the callback now **returns** the rendered string, and the session emits it as an event; renderers decide where it goes.

**Files:**
- Modify: `crates/alba-engine/src/event.rs` (new variant)
- Modify: `crates/alba-engine/src/watch/mod.rs` (`on_error` returns `String`; every `on_error(...)` call site sends the event)
- Modify: `crates/alba-cli/src/commands/run.rs` (`watch_execute`'s closure returns the string instead of printing)
- Modify: `crates/alba-cli/src/render/mod.rs`, `grouped.rs`, `interleaved.rs`, `json.rs`
- Test: engine watch tests + JSON wire test + existing CLI watch e2e (must stay green byte-for-byte)

**Interfaces:**
- Produces: `RunEvent::ProjectBroken { diagnostic: String }` — the *rendered* diagnostic (caret, help text), emitted whenever the session reports a `SessionError` (a Beamfile that stopped loading, a run that cannot be carried out).
- Changes: `alba_engine::watch`'s last parameter becomes `render_error: &mut (dyn FnMut(&SessionError) -> String + Send)`.
- Renderer contract: text renderers print `diagnostic.trim_end()` to **stderr** (Alba commentary, per the module's stdout/stderr rule); the JSON renderer emits `{"event":"project_broken","diagnostic":"..."}` on stdout **and** prints the diagnostic to stderr, preserving today's stderr behavior in JSON mode.

```rust
/// What a session can be told to do, by the TUI or any future driver.
#[derive(Debug)]
pub enum SessionCommand {
    /// Run `id` and its subgraph now. Retargets the session: subsequent
    /// watch triggers re-run `id` too. `force` empties the cache's read
    /// side for that one run. A run already in flight is cancelled first
    /// — same rule as a watch trigger, latest request wins.
    RunBeam { id: BeamId, force: bool },
    /// Cancel the run in flight; the session stays alive, waiting.
    CancelRun,
    /// Turn filesystem watching on or off. Does not touch a run in
    /// flight; only decides whether future batches trigger anything.
    SetWatch(bool),
    /// Cancel any run and end the session.
    Shutdown,
}

#[allow(clippy::too_many_arguments)]
pub async fn session(
    beamfile: &Path,
    project: Project,
    sources: SourceMap,
    target: BeamId,
    options: RunOptions,
    executors: Executors,
    events: UnboundedSender<RunEvent>,
    commands: Option<UnboundedReceiver<SessionCommand>>,
    watch_enabled: bool,
    cancel: CancellationToken,
    watcher: Box<dyn Watcher>,
    render_error: &mut (dyn FnMut(&SessionError) -> String + Send),
) -> WatchExit
```

- Consumes: everything Task 2 left in `watch/mod.rs` (`WatchSet`, `Trigger`, `relevant`, `merge`, `park_until_the_project_changes`, `display_paths`, `announce_recovery` — move them to `session.rs`; `beamfile_dir` and the path helpers stay in `watch/mod.rs` where their tests live, re-exported as today).
- `watch()` becomes:

```rust

    session(
        beamfile, project, sources, target, options, executors, events,
        None, true, cancel, watcher, render_error,
    )
    .await
}
```

- [ ] **Step 5: Implement command handling**

The shape, inside `session()`:

```rust
// A command receiver that is forever-pending when the caller passed
// None (headless watch), and treats a closed channel as Shutdown: a
// driver that dropped its sender is a driver that left.
let mut commands = commands;
async fn next_command(
    commands: &mut Option<UnboundedReceiver<SessionCommand>>,
) -> SessionCommand {
    match commands {
        Some(receiver) => receiver
            .recv()
            .await
            .unwrap_or(SessionCommand::Shutdown),
        None => std::future::pending().await,
    }
}
```

State added to the loop: `let mut watch_enabled = watch_enabled;` and `let mut force_next` gains a second producer (`RunBeam { force: true }`). The retarget is `target = id` before `continue`ing into the next iteration (the loop already rebuilds `WatchSet` and re-plans from `target` each pass — that is why `RunBeam` is nearly free).

Both `select!` loops (run phase and wait phase) gain one arm:

```rust
command = next_command(&mut commands) => match command {
    SessionCommand::RunBeam { id, force } => { /* run phase: remember (id, force) in a
        `pending_command: Option<(BeamId, bool)>`, cancel run_cancel; wait phase: retarget
        and break into the next run immediately */ }
    SessionCommand::CancelRun => { /* run phase: run_cancel.cancel(); wait phase: nothing */ }
    SessionCommand::SetWatch(enabled) => {
        watch_enabled = enabled;
        // wait phase only: re-announce the wait so a consumer sees the
        // toggle reflected (files count when on, nothing new when off)
        if enabled { let _ = events.send(RunEvent::WatchWaiting { files: set.file_count() }); }
    }
    SessionCommand::Shutdown => { /* run phase: run_cancel.cancel(), await the run
        future to wind down, return WatchExit::Interrupted; wait phase: return
        WatchExit::Interrupted */ }
},
```

Gating the watcher: batches are always *drained* (never stop polling `watcher.next_batch()` — a stalled watcher channel would buffer forever), but only classified into triggers when `watch_enabled` is true:

```rust
if watch_enabled && let Some(trigger) = relevant(&mut set, batch) { ... }
```

After the run phase, a `pending_command` takes priority over a pending watch trigger (`RunBeam` is the later, more explicit request); apply it as `target = id; force_next = force;` and continue into the next iteration without announcing `WatchWaiting`.

`WatchWaiting` emission in the wait phase becomes conditional: emit only when `watch_enabled` (spec: the non-watch TUI session shows a completed run, not a "waiting on files" state). The wait phase still waits (on commands and cancellation) when watch is off.

`park_until_the_project_changes` also gains the command arm (`Shutdown`/`RunBeam`/`SetWatch` must work while parked; `RunBeam` while parked retargets and retries the load once — a load that fails again re-parks).

```rust
//! Terminal setup and — above all — restoration.
//!
//! A TUI that panics without restoring the terminal leaves the user's
//! shell in raw mode with no echo: the cardinal sin. So the alternate
//! screen and raw mode are held by an RAII guard, doubled by a panic
//! hook that restores *before* the panic message prints — the message
//! must land on a terminal that can display it.

use std::io::{self, Stdout};

use crossterm::event::{DisableMouseCapture, EnableMouseCapture};
use crossterm::terminal::{
    EnterAlternateScreen, LeaveAlternateScreen, disable_raw_mode, enable_raw_mode,
};
use ratatui::Terminal;
use ratatui::backend::CrosstermBackend;

pub struct TerminalGuard {
    terminal: Terminal<CrosstermBackend<Stdout>>,
}

impl TerminalGuard {
    pub fn enter() -> io::Result<Self> {
        enable_raw_mode()?;
        let mut stdout = io::stdout();
        if let Err(error) =
            crossterm::execute!(stdout, EnterAlternateScreen, EnableMouseCapture)
        {
            let _ = disable_raw_mode();
            return Err(error);
        }

        // Restore before the default hook prints, chaining to it so the
        // panic message itself is not lost.
        let default_hook = std::panic::take_hook();
        std::panic::set_hook(Box::new(move |info| {
            restore();
            default_hook(info);
        }));

        let terminal = Terminal::new(CrosstermBackend::new(io::stdout()))?;
        Ok(Self { terminal })
    }

    pub fn terminal(&mut self) -> &mut Terminal<CrosstermBackend<Stdout>> {
        &mut self.terminal
    }
}

impl Drop for TerminalGuard {
    fn drop(&mut self) {
        restore();
    }
}

/// Idempotent, best-effort: called from the panic hook and from `Drop`,
/// possibly both. Errors are ignored — there is nothing to report them
/// to that this very restoration is not trying to fix.
fn restore() {
    let _ = disable_raw_mode();
    let _ = crossterm::execute!(io::stdout(), LeaveAlternateScreen, DisableMouseCapture);
}
```

```rust
pub async fn run(mut events: ..., commands: ..., options: TuiOptions) -> io::Result<TuiOutcome> {
    let mut guard = terminal::TerminalGuard::enter()?;
    let mut state = AppState::new(&options.target, options.watch);
    let mut input = crossterm::event::EventStream::new();
    let mut tick = tokio::time::interval(Duration::from_millis(80));
    tick.set_missed_tick_behavior(tokio::time::MissedTickBehavior::Skip);
    let mut dirty = true;

    while !state.should_quit {
        if dirty {
            let now = Instant::now();
            guard.terminal().draw(|frame| ui::draw(frame, &state, now))?;
            dirty = false;
        }
        tokio::select! {
            event = events.recv() => match event {
                Some(event) => {
                    state.apply(&event, Instant::now());
                    dirty = true;
                }
                None => break, // session ended (its own error path); leave cleanly
            },
            Some(Ok(event)) = input.next() => {
                dispatch(&mut state, &commands, input::action_for(&event, &state.mode));
                dirty = true;
            },
            _ = tick.tick() => {
                // durations and the bar tick between events
                dirty = state.running();
            },
        }
    }
    let _ = commands.send(SessionCommand::Shutdown);
    // Drain until the channel closes so the session's final events (the
    // cancelled run's summary) still reach the state and the replay.
    while let Some(event) = events.recv().await {
        state.apply(&event, Instant::now());
    }
    Ok(outcome(&state))
}
```

(`futures::StreamExt` provides `input.next()`. The 80 ms tick plus draw-on-event is the spec's ~30 fps cap: redraws coalesce because `dirty` batches whatever arrived since the last frame — with one refinement, biasing the select to drain all ready events before drawing: use `select!`'s default behavior plus the `dirty` flag; that is sufficient, no explicit batching needed.)

`dispatch` — the one place intent meets state and channel:

```rust
fn dispatch(state: &mut AppState, commands: &UnboundedSender<SessionCommand>, action: Action) {
    match action {
        Action::Quit => {
            if state.running() { state.mark_user_cancelled(); }
            state.should_quit = true;
        }
        Action::CancelOrQuit => {
            if state.running() {
                state.mark_user_cancelled();
                let _ = commands.send(SessionCommand::CancelRun);
            } else {
                state.quit_via_interrupt();
                state.should_quit = true;
            }
        }
        Action::Rerun { force } => {
            if let Some(beam) = state.selected_beam() {
                if state.running() { state.mark_user_cancelled(); }
                let _ = commands.send(SessionCommand::RunBeam {
                    id: BeamId(beam.id.clone()),
                    force,
                });
            }
        }
        Action::CancelRun => {
            if state.running() {
                state.mark_user_cancelled();
                let _ = commands.send(SessionCommand::CancelRun);
            }
        }
        Action::ToggleWatch => {
            state.watch_enabled = !state.watch_enabled;
            let _ = commands.send(SessionCommand::SetWatch(state.watch_enabled));
        }
        Action::SelectNext => state.select_next(),
        Action::SelectPrevious => state.select_previous(),
        Action::ScrollUp(lines) => state.selected_buffer_mut().scroll_up(lines),
        Action::ScrollDown(lines) => state.selected_buffer_mut().scroll_down(lines),
        Action::FollowTail => state.selected_buffer_mut().follow_tail(),
        Action::EnterSearch => state.mode = Mode::Search(SearchState::new()),
        Action::EnterCopy => state.mode = Mode::Copy(CopyState::new()),   // Task 11
        Action::EnterGraph => state.mode = Mode::Graph(GraphState::new()), // Task 12
        Action::EnterHelp => state.mode = Mode::Help,
        Action::LeaveMode => state.mode = Mode::Normal,
        Action::Key(key) => state.handle_modal_key(key),   // search/copy handlers
        Action::Mouse(mouse) => state.handle_mouse(mouse), // click=select, drag=copy
        Action::None => {}
    }
}
```

(`selected_buffer_mut` = `logs.entry(selected id).or_default()`. Until Tasks 11–12 land, `EnterCopy`/`EnterGraph` set `Mode::Normal` — wire them when their states exist; leave a `Mode::Help` render as part of this task's bottom-bar work only if trivial, otherwise Task 13 owns it.)

```rust
/// The spec's activation table: the TUI is the default on a terminal,
/// and yields to headless for CI, pipes, JSON, an explicit text layout,
/// or --no-ui. --ui forces it (it still needs a real terminal to draw
/// on; on a non-TTY it is refused with an error rather than corrupting
/// a pipe with escape codes).
fn ui_enabled(flags: &RunFlags, stdout_is_tty: bool) -> UiDecision {
    if flags.no_ui || flags.log_format == LogFormat::Json || flags.output.is_some() {
        return UiDecision::Headless;
    }
    match (flags.ui, stdout_is_tty) {
        (_, true) => UiDecision::Tui,
        (true, false) => UiDecision::RefusedNoTty,
        (false, false) => UiDecision::Headless,
    }
}

#[derive(Debug, PartialEq)]
enum UiDecision { Tui, Headless, RefusedNoTty }
```

```rust
//! The one test that runs the real plumbing: a pseudo-terminal, the real
//! binary, the real alternate screen. Deliberately small — confidence
//! comes from the layers below; this only proves they are actually wired.

use std::io::{Read, Write};
use std::time::{Duration, Instant};

use portable_pty::{CommandBuilder, PtySize, native_pty_system};

#[test]
fn the_tui_opens_restores_and_replays_on_q() {
    let project = tempfile::tempdir().unwrap();
    std::fs::write(
        project.path().join("Beamfile"),
        "version \"1\"\n\nbeam ok {\n  run \"echo hello-from-the-beam\"\n}\n",
    )
    .unwrap();

    let pty = native_pty_system()
        .openpty(PtySize { rows: 24, cols: 80, pixel_width: 0, pixel_height: 0 })
        .unwrap();
    let mut command = CommandBuilder::new(assert_cmd::cargo::cargo_bin("alba"));
    command.args(["run", "ok"]);
    command.cwd(project.path());
    let mut child = pty.slave.spawn_command(command).unwrap();

    let mut reader = pty.master.try_clone_reader().unwrap();
    let mut writer = pty.master.take_writer().unwrap();

    // Read until the alternate screen is entered, then quit.
    let mut seen = String::new();
    let deadline = Instant::now() + Duration::from_secs(30);
    let mut buffer = [0u8; 4096];
    let entered = loop {
        assert!(Instant::now() < deadline, "TUI never entered the alternate screen; got: {seen:?}");
        let read = reader.read(&mut buffer).unwrap();
        seen.push_str(&String::from_utf8_lossy(&buffer[..read]));
        if seen.contains("\u{1b}[?1049h") { break true; }
    };
    assert!(entered);

    writer.write_all(b"q").unwrap();
    writer.flush().unwrap();

    let status = child.wait().unwrap();
    // Drain what the quit produced.
    loop {
        match reader.read(&mut buffer) {
            Ok(0) | Err(_) => break,
            Ok(read) => seen.push_str(&String::from_utf8_lossy(&buffer[..read])),
        }
    }

    assert!(seen.contains("\u{1b}[?1049l"), "the alternate screen was never left");
    assert!(seen.contains("hello-from-the-beam") || seen.contains("succeeded"),
        "no trace of the run in the replay; got tail: {:?}", &seen[seen.len().saturating_sub(500)..]);
    assert_eq!(status.exit_code(), 0, "a green run quit with q exits 0");
}
```
